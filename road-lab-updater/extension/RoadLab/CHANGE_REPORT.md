# RoadLab 0.9.3 — unified sidebar

Expose all 19 existing road modifier inputs in organized, collapsed sidebar sections. Select a layer in the edge stack to edit its cross-section/crossing settings without selecting its generated object. Add material selectors, non-overwriting material import and missing-texture lookup. Individual layer settings default collapsed. These UI changes do not fix the road branch/junction mesh.

# RoadLab 0.9.2 — removal and open grass surfaces

Remove independent layers, preserve shared profiles, clear their point fields and reflow remaining layers. Grass uses an open surface and conforms its outer edge to the editable terrain base without a geometry dependency loop.

# RoadLab 0.9.1 — branch authoring

Add a separate connected spline at one selected road point while preserving through-road points and inheriting point fields. This is an authoring operation; junction surface validation remains incomplete.

# RoadLab 0.9.0 — naming, sections and sample package

Rename the plugin, reorganize labels and panels, provide editable main/stress samples and external node-library relinking.
